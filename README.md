# schwwaaa retro town portal

This package includes the updated Schwwaaa retro portal build.

## Files

- `index.html` — main landing page
- `projects.html` — extended mobile-responsive project catalog
- `styles.css` — shared styling for both pages
- `script.js` — low-bandwidth toggle and smooth in-page scrolling
- `assets/schwwaaa-logo.png` — Schwwaaa logo asset

## Notes
